# Inbox Intelligence 

Inbox Intelligence is an AI assistant designed to help manage email efficiently.

## Core Features

- Sort emails by priority
- Draft responses
- Summarize email threads
- Surface important opportunities

## Run the program

From the repository root, run the following command.

```sh
python3 main.py
```

Paste a line of email text at the prompt and press Enter to see its category.

## Run the tests

From the repository root, run the following command.

```sh
python3 -m unittest -v test_main
```
